## Installation Instructions:
### Android: APK installation
1. Download the latest APK (v2.0.0) at [Chill Chum Hub v2.0.0](https://github.com/ConnorRK8000/chill-chum-hub/releases/tag/v2.0.0)
2. Open APK file on mobile device and enable **"Allow from this source"** in settings if prompted
3. Click **Install**

### iOS: PWA Access
1. Open the link [connorrk8000.github.io/chill-chum-hub](https://connorrk8000.github.io/chill-chum-hub/) in Safari
2. Click share (box with an arrow pointing up)
3. Click **"Add to Home Screen"**

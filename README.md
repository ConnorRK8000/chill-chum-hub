## Installation Instructions:

### iOS & Android: PWA Access (Recommended)
1. Open the link [connorrk8000.github.io/chill-chum-hub](https://connorrk8000.github.io/chill-chum-hub/)
2. Add it to your device:
   * **iPhone (Safari):** Tap the **Share** button (box with arrow) ➔ select **Add to Home Screen**.
   * **Android (Chrome):** Tap the **three dots (⋮)** ➔ select **Install app** (or **Add to Home screen**).



### Android: APK installation
1. Download the latest APK (v2.0.0) at [Chill Chum Hub v2.0.0](https://github.com/ConnorRK8000/chill-chum-hub/releases/tag/v2.0.0)
2. Open APK file on mobile device and enable **"Allow from this source"** in settings if prompted
3. Click **Install**
